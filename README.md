# Vulnerable Software Reference

A curated reference of publicly disclosed vulnerable software versions, CVEs, and exploit resources organized by service, operating system, and privilege escalation category.

This repository is intended to help penetration testers quickly identify known vulnerable software during enumeration.

---

## Features

- Organized by service and port
- Linux and Windows coverage
- Initial access and privilege escalation
- Public CVE references
- Exploit-DB references
- GitHub PoCs
- Metasploit modules where applicable

---

## Disclaimer

This repository contains only publicly available vulnerability information collected from public sources such as Exploit-DB, NVD, GitHub, vendor advisories, and Metasploit.
It does **not** contain walkthroughs, lab solutions, proprietary training material, screenshots, or exploit chains for any commercial training platform.
This project is independent and is not affiliated with or endorsed by any training provider.

---

## Usage

### GitHub

Use GitHub's search or **Ctrl + F** to quickly locate software, versions, services, or ports.

### Obsidian

Import the Markdown file into an Obsidian vault for offline searching and note-taking.

### During Pentests

Use this reference during:

- Lab environments
- Capture The Flag (CTF) challenges
- Authorized penetration tests
- OSCP preparation
